# Library Management System

A console-based library management system that tracks patrons and the books they check out.

**Concepts:** structs/enums, `std::map`, `std::vector`, file I/O, string parsing

- Add, delete, and view library patrons (full name, address, phone number, library card number)
- Tracks checked-out books by genre (Non-fiction, Fantasy, Romance, Sci-Fi, Mystery, Horror, Other)
- Persists data using file I/O
