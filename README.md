# C++ Projects

A collection of some C++ programs from my time so far at University of Detroit Mercy, covering object-oriented design, data structures, file I/O, and algorithms.

## Projects

- [Course Enrollment System](course-enrollment-system/) — multi-class OOP course registration system with inheritance and corequisite tracking
- [Library Management System](library-management-system/) — patron and checked-out book tracker with file persistence
- [Theater Seating & Ticket Purchase System](theater-seating-system/) — seating chart and ticket sales simulator
- [Dice Roll Doubles](dice-roll-doubles/) — dice betting game simulator
